Viewer access

A second, read-only password so others can watch this dashboard: stats, graphs, map, packets, neighbours and public channels. Viewers never see DMs, room posts, alerts, settings, the console, updates, or this node's address and broker names.

Path ID size

How many bytes of this node's key it puts in packet paths when it adverts. Bigger IDs stop two repeaters being mistaken for each other, at the cost of fewer hops a flood can carry. Every size is still forwarded on MeshCore 1.14 and newer; nodes older than that may drop multi-byte paths, so match what your mesh uses.

Regional map

The CoreScope analyzer for your area. It names repeaters on the map and in packet paths, and tells the new-node alert who is already known. Leave blank to turn it off.

Settings backup

Saves name, location, radio, timing, repeat, adverts, Wi-Fi name, MQTT brokers and observer settings to a file. Passwords, MQTT tokens and keys are never put in it, so after restoring onto a new node you type those again.
